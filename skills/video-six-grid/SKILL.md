# 六宫格分镜

场景：【做饭】
人物：【黑发迷你卡通女孩】
剧情/动作：【帮忙做饭，中途偷吃、捣乱，最后被真人发现】
画面采用 真实摄影场景 + 迷你2D日系卡通人物 的混合风格。
在真实的【做饭】场景中，加入一个手掌大小的【黑发迷你卡通女孩】。

设计6个连续画面，让她围绕【帮忙做饭，中途偷吃、捣乱，最后被真人发现】展开一个完整的小故事

要求：

6格角色造型完全一致
每格动作和剧情有变化
小人物必须与真实人物、手部、食物或物体发生互动
不要只是站在旁边
真人可只出现手、身体局部或背影，不露脸
真实背景保持高清摄影质感
卡通人物保持可爱2D插画质感
剧情节奏：
出现 → 参与 → 互动 → 捣乱 → 搞笑高潮 → 可爱收尾

整体可爱、幽默、自然、有故事感

比例3:4，高清

只需要替换这3处：

①【做饭】→ 旅行 / 咖啡 / 收拾行李 / 工作 / 野餐……

②【黑发迷你卡通女孩】→ 短发女孩 / 戴帽女孩 / 自己的卡通形象……

③【帮忙做饭，中途偷吃、捣乱，最后被真人发现】
→ 换成你想要发生的故事
