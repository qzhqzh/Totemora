# ADR-0010：成员画像与受控演化

- 状态：Accepted
- 日期：2026-07-20

## 决策

成员画像分成四层，不能混成一段不断膨胀的提示词：

- **正式性格内核**：版本化的 traits、principles、communication style、working preferences 和 red lines。
- **观察画像**：从可归因任务推导出的稳定度、求助意识、抗系统噪声等带置信度指标。
- **任务履历与重大经历**：完成、验收成功、成员失败、系统失败，以及首次成功、累计里程碑、导师指点和正式升级。
- **成长提案**：建议改动、证据 ID、收益、风险、提案人和审批人。

初始正式画像来自成员配置。达到 `review_after_runs` 个新增已验证成功后，系统自动请导师或 Chief 生成证据约束的成长提案。成员不能评审自己；提案获批前不改变行为，获批后生成新版本并留下里程碑。

自动提案只允许修改 traits、communication style 和 working preferences。principles、red lines、权限、模型、Skill、谱系和历史属于受保护字段，不能由模型演化。经历作为不可信数据与系统指令分离，避免历史内容反向注入成员或导师。

## 理由

真正的成长不是“提示词越写越长”，而是可观察能力随任务证据变化，并以可审批、可追溯、可回滚的方式影响下一次工作。描述性画像可以自动更新；规范性人格必须治理。
