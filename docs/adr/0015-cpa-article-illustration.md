# ADR 0015：CPA 文章配图与“绘影”成员

## 状态

Accepted（2026-08-11）

## 决策

内容工坊增加第三名专业成员“绘影”。Chief 在文字完成独立审校后，将文章、编辑简报和明确验收标准交给绘影：

1. 绘影使用 CPA 文本火种生成结构化视觉简报。
2. `CpaIllustrationService` 使用 `gemini-3.1-flash-image` 渲染图片。
3. 绘影再以视觉模型检查语义、角色/风格一致性和手绘线稿质量；不通过时只允许纠正一次。
4. 图片与简报、提示词、模型、参考集、审核分数和失败原因一并保存。图片失败不删除已通过审校的正文。
5. Web 只提供预览、下载和人工重试；任何外部发布仍需单独授权。

## 协议事实

本地 CPA 的 Gemini 图片模型通过 `POST /v1/chat/completions` 返回 `choices[0].message.images[].image_url.url` 数据 URL。它不使用标准 `POST /v1/images/generations` 路径，因此以独立的窄接口适配，不改变现有文本 `AgentProvider` 契约。

## 安全与质量门禁

- API key 只从 CPA 本地配置文件读取，不进入仓库、数据库、提示词或日志。
- 只接受 JPEG、PNG、WebP data URL，限制为 16 MiB，并校验文件签名与尺寸。
- 参考图保存在运行数据目录，不作为公开 Web 静态目录；作品图片只能通过固定 work id 路由读取。
- 固定角色锚点：黑发、紫眼、黑色紫边服装、头顶黑色小鸟。
- 固定画风：1:1、大面积纯白留白、小人物、粗糙断续且有手抖感的线稿、无文字/Logo/水印。

## 后续

真实用户采纳信号累计后，再评估参考图选择、审核阈值与不同文章类型的视觉模板；不以“调用成功”替代成长证据。
