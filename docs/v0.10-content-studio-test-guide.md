# v0.10 内容工坊测试指南

## 启动

```bash
bun run dev:web
```

打开 `http://127.0.0.1:4310`；局域网部署沿用 `TOTEMORA_HOST=0.0.0.0`。操作员 Token 位于 `.totemora/operator-token`。

## 跑通一份内容

1. 在“听风台”先执行一次扫描，让候选消息池存在带来源的热点。
2. 到“创作工坊”选择 `X 热点短帖` 或 `教程 / 经验长文`，选择候选并点击“召集创作小队”。
3. 页面会依次显示等待召集、选题研究、撰写中和协作审校；模型调用慢时可以离开页面，Gateway 会继续工作。
4. 作品进入“可复制”后展开“协作证据”，应看到听风的研究、千工的写作与听风的独立审校。
5. 点击“复制正文”。在 HTTPS 下使用 Clipboard API；局域网 HTTP 下自动使用兼容复制。首次复制会把采纳反馈记入两名成员履历。

## 不定时创作

在“创作工坊”的“不定时创作”中开启开关，选择 1-168 小时内的最短/最长间隔以及作品类型。默认值为 6-18 小时且默认关闭。启用后下一运行窗口会显示在表单下方；只有候选池存在未使用、高可信候选时才会生成作品。

## 自动化验证

```bash
bun test packages/server/src/content-studio-service.test.ts
bun run typecheck
bun run lint
```

全量回归：

```bash
bun test
```

## 当前边界

- 当前只生成、审校和复制，不自动发布到 X 或博客。
- X 发布将来使用用户上下文 OAuth 和 `POST /2/tweets`，并在 Totemora 中增加独立审批、幂等键与远端回执。
- 自动创作不会复用已使用的候选；候选耗尽时等待下一轮情报扫描。
