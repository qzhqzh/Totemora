登记任务工作地

Totemora 只会在登记的服务器目录内续跑任务。请确认这是当前任务应被允许访问的项目目录。

开始托管任务

托管会写入明确 Goal，并在预算、截止时间和审批边界内续跑。系统审批仍只由你在 Web 端处理。

发送新指令

若当前 Turn 正在运行，指令会被 steer；否则会启动新的续跑 Turn。

订阅定时任务

只为指定任务创建一份独立凭证。当前用于本地 Codex Scheduled task：无需打开任务会话，但电脑和桌面应用必须保持运行。

定时任务凭证

Bearer Token 只显示这一次。把它放入本地 Codex MCP 使用的环境变量，仅把目标任务指令加入刚订阅的 Scheduled task；不要写进任务正文、仓库或聊天消息。
